**LeaseTracker AI – Idea Validation**

**1. Problem**

Small commercial property owners often manage lease information, rental payments, lease expiration dates, rent escalation, and occupancy using separate spreadsheets or manual records.

This makes it difficult to get a quick overview of the property portfolio and identify leases that may require attention.

**2. Target User**

The primary user is a small commercial property owner or property manager responsible for several commercial units and leases.

**3. Current Solution**

Lease information may be maintained manually using spreadsheets, calendars, payment records, and individual lease documents.

This can require the property owner to manually check several records to determine:

- current occupancy;
- rent due and collected;
- outstanding rent;
- upcoming lease expirations;
- pending renewals; and
- upcoming rent escalations.

**4. Proposed Solution**

LeaseTracker AI is a simple commercial lease management web application.

It brings basic property, lease, rent, and payment information into one dashboard.

The application tracks properties and units, calculates occupancy, monitors lease expiration and renewal, records monthly rental payments, and provides year-to-date financial summaries.

It also includes a lightweight AI capability to help identify leases that may require attention.

**5. Core Value**

Instead of manually checking several spreadsheet records, LeaseTracker AI presents the most important lease-management information in one place.

The user can quickly answer:

- How many units are occupied?
- How much rent should have been collected?
- How much has actually been collected?
- Which rents are overdue?
- Which leases are expiring?
- Which renewals are pending?

**6. Differentiating Angle**

LeaseTracker AI is deliberately designed as a lightweight commercial lease tracker for small property owners.

It focuses on essential lease-management information rather than the complexity of a full property-management or accounting system.

It also accommodates common commercial lease components such as:

- VAT;
- CWT;
- CUSA;
- CUSA VAT;
- rent escalation; and
- rent-free periods.

**7. Validation Decision**

Proceed with the project.

The problem is specific and practical, the target user is clear, and the application can be built as a manageable web application within the assignment period.

The first version will remain intentionally simple.

Features such as invoicing, accounting, automated email reminders, payment processing, tenant portals, and document management will remain outside the scope of Version 1.

## **Validation Evidence**

The problem is based on my own experience managing commercial lease information using spreadsheets and monitoring items such as monthly rent, VAT, CWT, CUSA, lease expiration, rent escalation, renewals, occupancy, and rent-free periods.

The sample dataset used to design and test LeaseTracker AI reflects these practical lease-management requirements. The data was anonymized for purposes of the assignment.

I validated the usefulness of the concept by checking whether the application could answer the main questions that would otherwise require reviewing several spreadsheet records:

- What is the current occupancy rate?
- How much rent and related charges are expected?
- How much has been collected?
- Which units are vacant?
- Which leases are approaching expiration?
- Which renewals require attention?
- What are the results for the entire portfolio and for each property?

## **Why Now**

AI-assisted development tools now make it practical for someone without recent programming experience to build a lightweight application around an existing business process.

LeaseTracker AI uses this opportunity carefully: financial and lease calculations remain deterministic, while AI is used only for the limited task of lease-attention classification.

## **Target User**

The primary target user is a small commercial property owner or property manager responsible for multiple units and leases who needs a straightforward way to monitor the portfolio without the complexity of a full enterprise property-management system.
