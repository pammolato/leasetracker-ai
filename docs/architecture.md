**LeaseTracker AI**

**Architecture Notes**

**1. Overview**

LeaseTracker AI is a lightweight web application for managing commercial lease information.

The application uses a simple architecture to keep the project easy to build, test, and deploy.

The main components are:

1. Web user interface
2. Lease data
3. Calculation and alert logic
4. AI lease-attention feature

---

**2. Web Application**

The application will provide three main areas:

**Dashboard**

Displays:

- occupancy rate;
- YTD rent information;
- YTD collections;
- outstanding rent;
- collection rate;
- property-level summaries;
- payment alerts;
- lease expiration alerts;
- renewal alerts;
- rent escalation alerts; and
- AI lease-attention results.

**Leases**

Displays information about:

- properties;
- units;
- tenants;
- lease dates;
- renewal status;
- basic rent;
- VAT;
- CWT;
- CUSA;
- CUSA VAT; and
- rent escalation.

**Payments**

Displays monthly payment information including:

- billing month;
- rent due;
- VAT;
- CUSA;
- CUSA VAT;
- CWT;
- expected cash payment;
- amount paid;
- payment date; and
- payment status.

Payment status may be:

- Paid
- Partially Paid
- Unpaid
- Rent Free

---

**3. Data**

The initial application will use anonymized sample lease data.

The data is organized into four groups:

Properties ↓ Units ↓ Leases ↓ Payments

Each unit belongs to a property.

Each lease belongs to a unit.

Each payment belongs to a lease.

The application will use sample data derived from the project's anonymized Excel workbook.

No confidential lease documents, tenant contact details, banking information, or tax identification numbers will be used.

---

**4. Application Logic**

Normal application code will perform calculations such as:

- occupancy rate;
- basic rent;
- VAT;
- CWT;
- CUSA;
- CUSA VAT;
- expected cash payment;
- YTD rent;
- YTD collections;
- outstanding balances;
- collection rate;
- days until lease expiration; and
- rent escalation.

These calculations will not use AI because they need to be predictable and mathematically accurate.

---

**5. Alerts**

Rule-based logic will identify items such as:

- overdue rent;
- rent due soon;
- lease expiration approaching;
- renewal pending; and
- upcoming rent escalation.

For example:

Payment past due and unpaid → Overdue

Lease expires within 90 days → Expiring Soon

Renewal status is Pending → Renewal Attention

---

**6. AI Capability**

The application will contain one lightweight AI capability.

The AI feature will classify leases according to the level of attention they may require.

Possible classifications are:

- High Attention
- Medium Attention
- Low Attention

The model may use information such as:

- payment status;
- overdue rent;
- lease expiration;
- renewal status; and
- upcoming rent escalation.

The AI feature will use a free local or open-source approach so that the project does not depend on a paid OpenAI or Claude API.

Financial calculations will never be generated by the AI model.

---

**7. Testing**

Automated unit tests will verify important calculations.

At minimum, tests will cover:

1. occupancy calculation;
2. rent and applicable charge calculation; and
3. rent escalation calculation.

Additional tests may cover:

- CWT turned off;
- CUSA turned off;
- rent-free periods; and
- overdue payment detection.

---

**8. Deployment**

The application will be stored in a public GitHub repository.

GitHub Actions will automatically run the project tests.

The web application will be deployed to a free hosting service that supports the selected application architecture.

Secrets will not be hardcoded in the source code.

---

**9. Architecture Flow**

User ↓ LeaseTracker AI Web Interface ↓ Properties / Units / Leases / Payments ↓ Calculation and Alert Logic ↓ Dashboard ↓ AI Lease-Attention Classification

---

**10. Design Principle**

Version 1 will remain deliberately simple.

LeaseTracker AI is a lease-monitoring application, not a full property-management, accounting, tax, or payment-processing platform.
